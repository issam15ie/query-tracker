Database Schema Information

Queries Table Schema

The main table storing all database query requests.

Column Name Data Type Description Status
id INTEGER PRIMARY KEY Unique identifier for each query Original
query_text TEXT The SQL query content Original
user_name TEXT Username who submitted the query Original
purpose TEXT Purpose/reason for the query Original
schema_name TEXT Database schema name Original
environment TEXT Environment (Dev, Test, Staging, Prod) Original
timestamp DATETIME When the query was created Original
parent_id INTEGER For versioning - links to original query Original
version INTEGER Version number for tracking edits Original
status NEW TEXT Query status (Pending, In Progress, Completed, etc.) Added ✅
priority NEW TEXT Priority level (Low, Medium, High, Critical) Added ✅
assigned_to NEW TEXT Who the query is assigned to Added ✅
completed_at NEW DATETIME When the query was completed Added ✅

Comments Table Schema NEW TABLE

New table for storing comments on queries.

Column Name Data Type Description
id INTEGER PRIMARY KEY Unique identifier for each comment
query_id INTEGER Links to the query being commented on
user_name TEXT Username who posted the comment
comment_text TEXT The comment content
timestamp DATETIME When the comment was posted

URL Parameter Handling

Direct links to specific queries with auto-highlight and scroll.

How It Works

When you include a ?query=ID parameter in the URL, the application will:

  • ✅ Automatically scroll to that specific query
  • ✅ Highlight it with a yellow pulsing border
  • ✅ Expand it if it was collapsed
  • ✅ Keep the highlight for 3 seconds

Try It Now:

http://10.10.44.224:3000/?query=64

This link will take you directly to query #64 and highlight it!

Where You See This:

  • In Emails: When you click "Send via Outlook", the email includes a direct link
  • Email Format: "View Query: http://10.10.44.224:3000/?query=64"
  • Result: Recipient clicks → Opens app → Scrolls to query → Highlights it
Test URL Parameter (Query #64)

How to Verify These Changes

1. Database Schema (New Columns)

  • Add a Query: Go to main page → Add new query
  • See New Fields: You'll see "Priority" and "Status" dropdowns
  • See Badges: After submitting, query card shows colored status/priority badges

2. Comments System

  • Open Any Query: Scroll to the bottom of any query card
  • See "Comments" Section: Click "Show Comments"
  • Add Comment: Type and click "Post Comment"

3. URL Parameter Handling

  • Send an Email: Click "Send via Outlook" on any query
  • Check Email Body: Look for "View Query: http://..."
  • Click the Link: Opens app and highlights that query
  • Or Test Manually: Add ?query=64 to the URL

4. Dashboard Permission

  • Profile Settings: Click your name in sidebar
  • My Permissions: See "View Dashboard" permission
  • User Management: (Admin only) See dashboard permission for all users
